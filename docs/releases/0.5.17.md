# TFX 0.5.17

- «Чёрная дыра», «Котик», «Аквариум» и новогоднее оформление перерисованы в пикселях, в масштабе темы «8 бит».
- Все они теперь живут только в узкой полосе у нижнего края окна. Шапка, список чатов и сообщения остаются свободными, вода больше не заливает окно.
- Снегопад: резные снежинки, гирлянда сверху, еловые ветки и морозные узоры убраны, снег падает как раньше. На пиксельном сугробе стоят маленькие ёлки, снеговик и подарки, по гребню лежат огоньки.
- Новые темы стали в разы легче для компьютера.
