# TFX 0.5.12

- В теме «Сакура» появились две асимметричные ветки в верхних углах. Их силуэт и тёплые оттенки коры взяты из осеннего эффекта.
- Предпросмотр и оверлей Telegram используют общую геометрию веток. При изменении размера окна они сохраняют пропорции и остаются в углах.
- Новые лепестки падают сверху и мягко реагируют на движение курсора.
- Из окна настроек убран блок «Проверить обновления».
