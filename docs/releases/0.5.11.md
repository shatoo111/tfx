# TFX 0.5.11

- Обновлено оформление окна настроек: голубой градиент с индиго по краям, бирюзовые активные состояния и встроенный Inter с кириллицей.
- У образцов эффектов теперь тёмно-синяя сцена с тонкой сеткой. Светлые капли, снежинки и лепестки лучше видны на этом фоне.
- Обновлены иконки приложения для Windows и macOS.
- На экранах с высоким масштабом окно настроек открывается с учётом доступной высоты. Все настройки доступны через прокрутку.
