- Предварительная версия показывает суффикс и предлагает стабильное обновление с тем же номером.
- Архив macOS поддерживает Apple Silicon и Intel. TFX проверяет архитектуру и подпись пакета перед закрытием текущей версии. Если новая версия не покажет окно настроек, установщик возвращает прежний пакет.
- После окончательной остановки графического слоя TFX возвращается к обычному интервалу опроса Telegram.
- В экономичном режиме настройки показывают ограничение в 30 кадров/с. Выбранная частота для обычного режима сохраняется.
