# Приватность

Через несколько секунд после запуска, затем раз в четыре часа и при возврате в окно (не чаще раза в полчаса) TFX запрашивает `https://tfx-site-ashy.vercel.app/api/releases`, чтобы узнать номер последней версии. В запросе нет cookie, идентификаторов и номера установленной версии; хостинг сайта видит IP-адрес, как при открытии любой страницы. Если версия новее, внизу окна появляется плашка со ссылкой на сайт. Сама программа ничего не скачивает и не устанавливает. События эффектов, размеры окна и ошибки графики остаются в журнале на 160 записей в памяти. Пользователь может скопировать его в буфер обмена.

## Что используется

| Платформа | Данные и API | Назначение |
| --- | --- | --- |
| Windows | Foreground HWND, PID, путь executable, DWM bounds, visibility/cloaking, virtual desktop membership | Найти Telegram или клиент на его основе и разместить overlay |
| Windows | Команда открытия ссылок tg:// в HKCU\Software\Classes | Узнать клиент, которого нет в списке |
| Windows | Out-of-context WinEvent hooks | Узнать о перемещении, сворачивании и смене активного окна |
| Windows | GetCursorPos / ScreenToClient | Рассчитать отклонение частиц без перехвата ввода |
| macOS | NSWorkspace running/frontmost applications, bundle identifier | Найти Telegram или клиент на его основе |
| macOS | Info.plist запущенных программ: схемы ссылок | Узнать клиент, которого нет в списке, по ссылкам tg:// |
| macOS | Quartz window list: PID, number, layer, alpha, bounds | Выбрать видимое окно и его прямоугольник |
| macOS | NSEvent.mouseLocation | Положение курсора без event tap |

WinEvent hooks уведомляют о **событиях окна**; это не клавиатурный / мышиный перехват и не внедрение DLL. Поля заголовков, даже если они присутствуют в системном списке, не извлекаются и не логируются. Нет UI Automation / Accessibility обхода содержимого сообщений, screenshots, чтения памяти Telegram или доступа к его каталогам / токенам.

Пока по нижнему краю активного окна Telegram идёт гость парада (тема The United States), TFX сверяет текущую позицию курсора с местом гостя: под курсором он здоровается. В это время TFX также получает уведомления о клике в окне Telegram через NSEvent на macOS и WH_MOUSE_LL на Windows. Telegram получает исходный клик. Координаты используются только в памяти.

## Разрешения macOS

Базовый путь использует только метаданные окон и не запрашивает Accessibility или Screen Recording. Снимки экрана не создаются. Если версия macOS перестанет возвращать нужную геометрию, приложение скрывает эффект и показывает диагностический статус; оно не обходит ограничения и не вызывает запрос Screen Recording.

Возможный будущий AXObserver потребует Accessibility для уведомлений о геометрии чужого окна. Он не реализован и разрешение на него не запрашивается. Добавление такой функции потребует отдельного объяснения в интерфейсе и явного действия пользователя.

## Хранение

Настройки: QSettings, organization `TelegramEffects`, application `TelegramEffects` (HKCU на Windows, preferences plist на macOS). Запись откладывается на 250 мс при движении слайдера и завершается при выходе. Автозапуск выключен до действия пользователя; фактическое состояние определяется по регистрации в ОС.

Windows создаёт только своё значение `TelegramEffects` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. macOS создаёт только `~/Library/LaunchAgents/org.telegrameffects.desktop.plist` с путем текущего executable и `--background`. Root, системные расширения и вспомогательный привилегированный процесс не нужны. Отключение автозапуска удаляет только собственную запись.

`instance.lock` в AppLocalDataLocation предотвращает две копии overlay. Для полного удаления сначала выключите автозапуск и завершите приложение, затем удалите его файлы и, по желанию, собственные preferences. Не изменяйте настройки защиты ОС ради запуска неподписанной сборки.
