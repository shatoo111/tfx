# Обязательная приёмка перед стабильным релизом

Заполнить отдельно на Windows 10, Windows 11, macOS Apple Silicon и macOS Intel. Приложить версии ОС, Telegram Desktop, Qt, GPU, число мониторов и масштабы; не записывать содержимое переписок. **Ни один пункт ниже пока не означает выполненную проверку.**

| Проверка | Ожидаемое поведение |
| --- | --- |
| Запуск без Telegram, затем запуск Telegram | Ожидание, затем эффект над окном Telegram |
| Клики в чатах, выделение, скролл, ввод, drag/drop, контекстное меню | Все действия получает Telegram; overlay не получает фокус |
| Перемещение / live resize / maximization | Слой следует границам, снег обрезан окном, нет старого прямоугольника |
| Alt-Tab / Cmd-Tab, другое окно поверх Telegram | Эффект остаётся на видимой части Telegram, перекрывающее приложение остаётся поверх эффекта |
| Minimize, закрытие, выход и повторный запуск Telegram | Слой исчезает; новый процесс распознаётся |
| Переход между окнами Telegram, медиапросмотрщик, звонок | Нет снега над посторонним приложением; отметить неподдержанные типы окон |
| Telegram full screen | Не перехватывается фокус; выход из full screen не оставляет слой на другом Space |
| Windows virtual desktops / macOS Spaces | На рабочем столе без Telegram нет снега |
| Mission Control, Stage Manager, Win+Tab | Overlay не создаёт отдельную интерактивную плитку и не остаётся поверх обзора окон |
| Lock / unlock, sleep / wake, disconnect monitor | Слой скрывается / корректно восстанавливается без скачка симуляции |
| 100/125/150/200% Windows DPI, Retina + внешний дисплей | Нет смещения окна или взаимодействия курсора |
| Монитор слева / сверху от главного; окно между мониторами | Корректны отрицательные координаты, нет смещения на DPR |
| Light / Normal / Blizzard и крайние значения ветра | Отличимы плотности, нет разрывов / вспышек частиц |
| Накопление 2–5 минут, изменение максимума, clear | Ограниченная неровная поверхность, плавное сглаживание, мгновенная очистка |
| Проведение курсором через частицы и сугроб | Отклонение и разлёт при сохранении кликабельности Telegram |
| Выключение эффекта | Слой исчезает сразу, счётчик кадров больше не растёт |
| Выключение накопления | Старый снег тает, новые частицы не накапливаются |
| Перезапуск Telegram Effects | Все настройки восстановлены |
| Снег → дождь → снег | Меняются частицы и подписи настроек; параметры снега сохраняются |
| Лёгкий / обычный дождь / ливень | Три различимые плотности, ветер меняет наклон капель |
| Высота травы 0–160, выключение травы | Трава меняет высоту или исчезает, дождь продолжается |
| Движение курсора по траве, затем выключение взаимодействия | Трава отклоняется и возвращается; при выключении реагирует только на погоду |
| Гроза на каждом уровне дождя, интервалы 5 / 15 / 60 секунд | Приглушённые вспышки с разбросом интервала ±25%, разными центрами и наклоном |
| Выключение дождя, сворачивание Telegram, пробуждение | Симуляция затихает или приостанавливается; при возврате нет серии накопленных вспышек |
| Автозапуск ON, logout/login, OFF, logout/login | В первом случае один фоновый экземпляр, во втором автоматического запуска нет |
| Закрытие настроек; повторное открытие из меню | Приложение продолжает работать, окно настроек можно вернуть |
| Нет системного трея | Настройки не стартуют скрытыми; закрытие завершает приложение |
| Чистая ОС без Qt в PATH | Установленный `.app` / весь portable каталог запускается самостоятельно |

## Подтверждение релиза

Зафиксировать тег, SHA, дату и результаты каждой строки отдельно для реального Telegram Desktop на Windows и macOS. Стабильную публикацию разрешает параметр `manual_qa_passed` после прохождения списка. Предварительные пакеты имеют метку pre-release.

| Сценарий | Критерий |
| --- | --- |
| Сначала Telegram, затем TFX; затем обратный порядок | В обоих случаях без клика в настройках появляются кадры на видимом Telegram |
| Быстро снег → дождь → сакура, выключить во время смены, включить снова | Один слой, старая тема исчезает, после выключения кадры прекращаются |
| Перемещение, изменение размера, максимизация и полный экран, другой DPI, окно поверх Telegram | Совпадают четыре границы и порядок окон, соседние окна остаются поверх |
| Сон, пробуждение, смена рабочего стола, два окна Telegram | Один слой на нужном видимом окне, при возврате снова идут кадры |
| Потеря графики и повторяющаяся ошибка | После краткого сбоя слой оживает, после трёх неудач видна причина |
| Шесть тем, три сочетания, ветки, экономия и системное уменьшение движения | Настройки переживают переключения и перезапуск, уменьшение движения ставит слой на паузу |
| Обновление предыдущей версии и отказ в доступе к GitHub | Успех сохраняет настройки, остаётся один пакет приложения, ошибка объяснена |
| Диагностика | В буфере есть времена, состояние, размеры и сбои, отсутствуют заголовки окон и содержимое чатов |
| Загрузка macOS через браузер на чистом Mac | Developer ID, нотариальный билет и Gatekeeper проходят проверку |
| CPU, GPU, батарея | Записать модель, питание, время наблюдения, фон, обычный/экономичный режим и результат по каждой метрике |

## Производительность

Измерять **Release** после 30 секунд прогрева. Для каждого режима: окно 1000×700 и 4K, 30/60 FPS; 120 секунд на измерение. Снять CPU, память, GPU, фактическую частоту представления и задержку при перетаскивании. Использовать Instruments / Activity Monitor и Windows Performance Analyzer / Task Manager.

Повторить после сворачивания Telegram и после полного таяния: не должно быть непрерывных вызовов update() / кадров Scene Graph. Редкие проверки метаданных окон остаются. Не заявлять конкретный процент CPU или гарантированные 60 FPS до измерений.

## Ошибки и приватность

- Запуск без разрешений Screen Recording / Accessibility должен работать, если ОС отдаёт метаданные окон. Проверить отсутствие запроса этих разрешений.
- Проверить сохранение при read-only каталоге настроек: интерфейс сообщает ошибку.
- Проверить повреждённые значения в INI отдельно через `settings_tests`.
- Проверить графический backend через `QSG_INFO=1`; сохранить лог без заголовков окон и переписок.
- Не считать `--smoke-test` доказательством click-through, Retina/DPI, full screen или положения overlay.
